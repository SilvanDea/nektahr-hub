# Каталог заказов — предлагаемая структура

Каталог дополняет галерею и прайс. Галерея — архив работ, прайс — общие правила и калькулятор, каталог — конкретные актуальные YCH/адопты, доступные для заказа независимо от ограничений отдельных площадок.

## Карточка лота

- Название и постоянный ID лота.
- Тип: YCH / Adoptable; фильтр SFW / NSFW с общим подтверждением возраста.
- Статус: открыт / забронирован / продан / доступность уточняется.
- Превью; для YCH — шаблон, пример результата и доступные альт-версии.
- Базовая цена либо стартовая ставка/автовыкуп; состав, опции и срок.
- Ссылки на площадки, на которых размещён именно этот лот.
- «Собрать заявку»: выбранный лот и его варианты попадают в заявку с ID и расчётом.

## Правила наполнения

Доступность не выводится из самого наличия картинки в галерее. Старые демонстрационные YCH не помечаются открытыми без подтверждения. После продажи одной карточке обновляется статус, а не создаются независимые копии по площадкам. Прямой заказ согласуется с художником; сайт не обещает автоматическую оплату или резервирование.

Для запуска нужны актуальные лоты, их цены, доступность и ссылки. Каталог пока не добавлен в навигацию: это план отдельного раздела, а не пустая витрина с неподтверждёнными заказами.
