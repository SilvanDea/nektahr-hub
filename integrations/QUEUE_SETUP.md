# Обновление публичного API очереди

Сайт уже использует текущий публичный endpoint. Кэш на стороне браузера и новая таблица работают без смены URL.

## Почему нужен этот скрипт

Текущая версия endpoint отдаёт `displayName`, `orderType`, `title`, `status`, `progress`, `sortOrder`, `startedAt`, `estimatedCompletion`. Она не передаёт номер заказа и дату принятия. В `queue-manager.js` добавлена точная метаинформация только для уже существующей публичной строки NT-021. Для других новых строк без этих полей интерфейс показывает «—», а не выдумывает номер или дату.

## Одноразовое обновление

1. Открой Apps Script, связанный с существующей таблицей очереди.
2. Сохрани копию текущего кода и замени endpoint кодом `queue-api.gs`.
3. Убедись, что лист публичного вывода называется `Queue`. Если имя отличается — измени `PUBLIC_QUEUE_SHEET`.
4. В **существующем** веб-развёртывании выбери новую версию и обнови его. Не создавай новое развёртывание: так сохранится URL, уже указанный в сайте.
5. Проверь публичный ответ: `orderId`, `acceptedAt`, `estimatedCompletion`, `reservationUntil`. Тестируй только строки с `Public=TRUE`.

Код может работать как связанный с таблицей скрипт без ID в исходниках. Для отдельного скрипта владелец задаёт `QUEUE_SPREADSHEET_ID` в Script Properties. Не публикуй финансовую книгу целиком и не включай публичный доступ к её внутренним листам.

## Колонки Queue

Существующие колонки сохраняются. `Order ID`, `Title`, `Status`, `Public` обязательны.

- `Accepted At` — дата принятия заказа. Если отсутствует, endpoint берёт только `Order Date` из листа `Orders` по совпадающему `Order ID`.
- `Estimated Completion` — ориентировочный срок сдачи; пустое поле отображается как «Согласуется».
- `Reservation Until` — необязательная дата окончания брони.
- Для брони используй `Status=Reserved` и `Public=TRUE`. Добавь `Reserved` в список допустимых значений столбца Status, если он ограничен dropdown-валидацией.
- `On Hold` остаётся паузой в уже принятой работе и не превращается в бронь.
- `Completed`, `Cancelled`, `Delivered` не показываются в активном списке.

Внутренние Notes, имена клиентов, платежи и другая финансовая информация в JSON не попадают. Исходная таблица в этом обновлении сайта не менялась.

## Быстродействие и актуальность

- Запрос начинается после разбора HTML, не ждёт загрузки всех изображений.
- Последний успешный публичный ответ хранится в браузере до суток и помечается временем обновления.
- При переходах между страницами ответ моложе 45 секунд переиспользуется; затем обновляется в фоне.
- На видимой странице очереди обновление каждые 2 минуты, вручную — кнопкой «Обновить».
- Новая версия Apps Script кэширует публичный JSON на 60 секунд. Первую задержку холодного старта Google убрать только фронтендом нельзя.

## Бронь и оплата

Интерфейс позволяет связаться и обсудить бронь. Он не создаёт её автоматически и не обещает неподтверждённых условий. Отдельная плата за бронь не установлена. Срок, подтверждение и возможный аванс согласуются художником с клиентом.
