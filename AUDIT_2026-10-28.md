# Аудит, отладка и ремонт Nek’tahr Hub — 28 октября 2026

## A. Общая оценка

**READY WITH LIMITATIONS — готово с ограничениями.** Основные сценарии статического сайта проверены, подтверждённые дефекты исправлены. В проверенном объёме не осталось известных критических или высоких блокирующих ошибок. Это не означает отсутствие всех возможных уязвимостей или подтверждение production-развёртывания.

Проверены семь HTML-маршрутов, восемь JS-модулей, данные каталога и галереи, соответствующие CSS-правила, образец Apps Script API и инструкции подключения. Сайт без сборки: повторяющиеся HTML-страницы используют общие JS/CSS, публичный JSONP endpoint Google Apps Script и браузерный кэш. Каталог формирует обращения к художнику; платежей и автоматического списания доступности нет. Производственная ветка и внешний Google workbook не изменялись. Перед ремонтом сохранён локальный архив baseline; изменения обратимы через историю тестовой ветки.

## C. Внесённые изменения

- Все семь HTML: сессионное подтверждение ToS, согласованный reset, aria-current, декоративный alt, версия ссылок на assets `20261028-audit11`.
- `assets/queue-manager.js`: строгая обработка явных Public-флагов, отбрасывание массивов, минимальная проекция кэша v4, tabindex вкладок.
- `assets/process-viewer.js`: обработка ошибок основного изображения и обеих сторон сравнения.
- `tests/queue-regression.cjs`: изолированные тесты реального клиента и образца Apps Script; не обращаются к реальной таблице.
- `tests/runtime-regression.cjs`: реальные функции расчёта, состояние ToS, reset и обработчики ошибок изображений.
- `tests/validate-project.py`: маршруты, ID, ссылки, общность бизнес-логики, данные, все локальные изображения и ограниченный поиск шаблонов секретов.
- `tests/README.md`: воспроизводимые команды и границы тестов.

Цены, уровни, включённые альтернативы, правила продажи YCH/адоптов, NSFW-пары и доступность лотов сохранены. Новые зависимости приложения не добавлены. Старые fallback-функции HTML не удалялись без необходимости.

## E. Оставшиеся ограничения

1. **Внешняя инфраструктура:** Google workbook и актуальное production-развёртывание Apps Script не изменены и не проверены изнутри. Тесты сервера относятся к приложенному `integrations/queue-api.gs`, а наблюдение живой очереди — к её интерфейсу. Не заменять полный финансовый скрипт одним endpoint-файлом без сохранения остальных функций.
2. **Зависимости:** Tailwind CDN, Google Fonts, Google Apps Script и два уникальных старых внешних изображения остаются внешними зависимостями. Доступность/компрометация их инфраструктуры не проверена; CSS-компиляция и самостоятельный хостинг зависимостей в этом аудите не вводились.
3. **18+ и изображения:** blur/предупреждение — интерфейсный фильтр. Файлы статического публичного сайта доступны по URL; запрет ПКМ не защищает от DevTools или скриншота. Подтверждение 18+ в браузере не принято; сценарий после реального подтверждения проверяется владельцем вручную.
4. **Копирование:** из-за виртуального clipboard нельзя независимо подтвердить Ctrl+V в обычном браузере.
5. **Экраны и окружения:** браузерная проверка проведена при доступном viewport 1363 px. CSS media rules просмотрены, но полноценные проверки физических телефонов, Safari/Firefox, screen reader и иных размеров не заявляются. Ранее мобильный интерфейс был отложен владельцем.
6. **Содержание:** неизвестным персонажам оставлены нейтральные названия; их личности и тип заказа подтверждает художник. Аудит не меняет финансовые условия или неподтверждённую доступность лотов.
7. **Состояние:** подтверждение ToS сохраняется только в доступном sessionStorage текущей сессии/ревизии, не в аккаунте. При изменении условий нужно изменить ревизию ключа. Остальные черновики формы не обещаны как долговременное хранилище.

## F. Как применить и проверить

Исправленные файлы включены в новый архив и сохранены только в `feature/multi-page-migration`. `main` и production не обновляются.

Локальная проверка в Windows PowerShell после распаковки архива:

```powershell
cd "C:\путь\к\распакованному\сайту"
py -m http.server 8080
```

Открыть `http://localhost:8080/`. Не открывать HTML через file://: абсолютные пути и fetch каталога требуют HTTP-сервера.

Повторить автоматические тесты (Node.js; для проверки изображений Python с Pillow):

```text
node tests/queue-regression.cjs
node tests/runtime-regression.cjs
python tests/validate-project.py
```

Вручную проверить в обычном браузере:

1. На Pricing custom выбрать sketch ($80), затем Reset: full render ($200). Выбрать adopt $200 и разные включённые альтернативы; не должно добавляться $50 за включённый выбор.
2. Выбрать YCH $60 и AB $160. Скопировать заявку и вставить в блокнот; проверить пакет, версии и сумму.
3. Прочитать текущие ToS и **самостоятельно** отметить подтверждение, затем перейти на Pricing: заявка должна содержать подтверждение. Снять отметку и повторить: подтверждение должно исчезнуть.
4. При желании самостоятельно проверить положительное подтверждение 18+ и повторное скрытие. После отмены контент должен оставаться размытым.
5. Проверить очередь: refresh, активные заказы и бронь. Для изменения backend использовать отдельную резервную копию таблицы и существующего полного скрипта; production API в этом аудите не переустанавливался.
